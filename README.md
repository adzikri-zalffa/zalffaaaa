
# Andra ♡ Zalffa

Website romantis dengan pemutar musik, animasi halaman, timer hubungan,
galeri foto, dan surat cinta.

## Daftar file

- index.html
- styles.css
- script.js
- README.md
- couple-1.jpg
- couple-2.jpg
- zalffa.jpg
- andra.jpg
- album.jpg
- music.mp3

Letakkan semua file di root repository, bukan di dalam folder tambahan.

## Mengaktifkan GitHub Pages

1. Upload semua file ke repository.
2. Buka Settings > Pages.
3. Pilih Deploy from a branch.
4. Pilih branch main dan folder /(root).
5. Tekan Save.
6. Buka alamat website yang ditampilkan GitHub Pages.

## Catatan

Nama file foto harus sama persis dengan nama yang digunakan di HTML.
File music.mp3 harus berupa audio yang kamu punya izin untuk gunakan.
Tekan tombol Play untuk memulai musik karena browser dapat memblokir
audio otomatis dengan suara.

Animasi perpindahan halaman menggunakan CSS tanpa library tambahan.
